# Plan: Replace the W/B readout with a slump prediction in the explorer

**Goal**: The strength-curve panel's readout strip shows `GWP · Cost · Slump` — three
predicted outcome properties — instead of `GWP · Cost · W/B`, with slump backed by a real
client-side GP posterior (mean ± 2σ) exported from `boxcrete.fit_slump_gp`.

**Architecture**: A new, deliberately *separate* JS predictor (`docs/slump.mjs`) fed by a new
artifact (`docs/model/slump.json`) generated by a new Python exporter
(`experiments/regenerate_slump_json.py`). The strength port in `docs/gp.mjs` is not
generalized — see "Why a separate module" below. Golden-vector parity tests mirror the
existing Python↔JS discipline.

**Tech stack**: Python 3.12 / BoTorch / GPyTorch (fit + export), vanilla ES modules (browser),
Node for unit tests, Playwright for e2e, `make` for the suites.

### Verified facts that drive the design

1. **`SingleTaskGP`'s default kernel here is ARD `RBFKernel` with no `ScaleKernel`** — not the
   Matérn the `slump_model.py` docstring (lines 6-14) claims. Confirmed by fitting:
   `covar_module` is `RBFKernel`, `lengthscale.shape == (1, 10)`, no `outputscale` attribute.
   The exporter must **read** the kernel type off the model and hard-fail on anything else,
   never assume. The stale docstring gets fixed in Step 0.
2. **`mean_module` is `ConstantMean`** (fitted value ≈ `0.0261` in standardized space), not the
   `ZeroMean` the strength model uses. The JS posterior must add the constant.
3. **`Standardize(1)`**, not max-scaling: `means ≈ 6.8098 in`, `stdvs ≈ 2.9598 in`.
4. **`AppendDerivedFeatures` uses `binder.clamp(min=1.0)`, i.e. `hrwr / max(binder, 1.0)`**
   (`boxcrete/features.py:277-283`). `FEATURE_FNS.hrwr_binder` in `docs/feature_registry.mjs:41`
   uses `hrwr / (binder + 1.0)` — a **different formula**, mirroring `FEATURE_BUILDERS` for the
   strength model. Reusing it would silently break parity by ~0.3%. `docs/slump.mjs` implements
   `max(binder, 1.0)` itself; a test pins the distinction.
5. **Slump has zero data for Material Source 0 (mortar).** Training bounds on dim 7 are
   `[1, 2]`. 69 of the 149 catalog mixes are Source 0. Per product decision: show `n/a`.
6. **The sliders far exceed slump's support in almost every dimension** (e.g. Slag `0–1198`
   vs `0–367`; HRWR `0–13.3` vs `0–4.63`; Coarse Agg `0–1356` vs `928–1356`). This is handled
   by the ±2σ band, which correctly blows up to ≈ ±6.6 in far from data. No new gating.
7. `cholesky` and `solveTriangularLower` are **already exported** from `docs/gp.mjs:613`.

### Product decisions (confirmed with the user)

- Material Source 0 → render `n/a` with an explanatory tooltip. Do not predict.
- W/B leaves the readout strip entirely; the `computed:wb` scatter filter stays.
- Uncertainty rendered as `± X (2σ)`, matching the Cost readout convention.

### Why a separate module rather than generalizing `docs/gp.mjs`

`gp.mjs::transformInput` (191-209) unconditionally applies `log10(t + log_time_offset)` to
`params.time_dim_raw`, and `kernel()` (150-170) unconditionally multiplies in the time gate and
the RBF-time term. Slump is time-independent and has no such dim. Making those schema-optional
touches the hottest path in the app — the one that renders the strength curve at 60 fps and is
pinned by `test_js_gp.mjs`, `test_js_strength_v2.mjs`, `test_js_predictor_parity.mjs`, and
`test_curve_monotonicity.mjs`. The slump posterior is ~50 lines over a 61×61 matrix. A separate
module is smaller, safer, and independently testable. `docs/slump.mjs` imports `cholesky` and
`solveTriangularLower` from `gp.mjs` so the linear algebra is shared, not duplicated.

### The math `docs/slump.mjs` implements

Given raw composition `x` (9 dims, no Time), params `P` from `slump.json`:

```
1. augment:    xa = [...x, hrwr / max(cement + flyAsh + slag, 1.0)]        // 10 dims
2. normalize:  xn[d] = (xa[d] - P.normalize_lower[d])
                       / (P.normalize_upper[d] - P.normalize_lower[d])     // no clamping
3. kernel:     k(a, b) = P.outputscale * exp(-0.5 * Σ_d ((a[d]-b[d]) / P.lengthscales[d])²)
4. once:       K   = k(X_train, X_train) + P.noise * I
               L   = cholesky(K)
               α   = L⁻ᵀ L⁻¹ (Y_train - P.mean_constant)
5. per call:   k*  = k(X_train, xn)
               μ_s = P.mean_constant + k*·α
               v   = L⁻¹ k*
               σ²_s = P.outputscale - v·v  (+ P.noise if variance_includes_aleatoric)
6. destandardize:
               mean     = μ_s   * P.y_std + P.y_mean          // inches
               variance = σ²_s  * P.y_std²                    // inches²
```

Note `k(x,x) = outputscale` exactly, because RBF is stationary and normalization is affine.

### 1a. Write the exporter

```python
# Copyright (c) Meta Platforms, Inc. and affiliates.
#
# This source code is licensed under the MIT license found in the
# LICENSE file in the root directory of this source tree.

"""Export the slump GP to docs/model/slump.json for the web explorer.

Writes two files from a SINGLE fit (the MLL objective is non-convex, so two
runs land on different optima and the golden vectors would not match the
shipped model):

  * docs/model/slump.json              — kernel ingredients for docs/slump.mjs
  * docs/model/slump_test_vectors.json — Python-reference posteriors

Like the strength exporter, this deliberately does NOT ship the Cholesky
factor or alpha: JS rebuilds K and factors it, so both sides reach the same
posterior from the same kernel evaluations instead of inheriting Python's
factorization.

Usage: python experiments/regenerate_slump_json.py
"""

from __future__ import annotations

import json
from pathlib import Path

import torch
from botorch.models.transforms.outcome import Standardize
from gpytorch.kernels import RBFKernel
from gpytorch.means import ConstantMean

from boxcrete.slump_model import fit_slump_gp
from boxcrete.utils import load_concrete_strength, SLUMP_Y_COLUMNS

SEED = 0
REPO = Path(__file__).resolve().parent.parent
OUT = REPO / "docs" / "model" / "slump.json"
OUT_VECTORS = REPO / "docs" / "model" / "slump_test_vectors.json"

# Material Source classes with slump observations. Mortar (class 0) has none:
# workability there is measured by flow table, not a slump cone. The explorer
# renders "n/a" for classes outside this list rather than extrapolating.
SUPPORTED_SOURCE_CLASSES = [1, 2]

RAW_FEATURE_NAMES = [
    "Cement (kg/m3)",
    "Fly Ash (kg/m3)",
    "Slag (kg/m3)",
    "Water (kg/m3)",
    "HRWR (kg/m3)",
    "Fine Aggregate (kg/m3)",
    "Coarse Aggregates (kg/m3)",
    "Material Source",
    "Temp (C)",
]


def main() -> None:
    torch.manual_seed(SEED)

    print("[regenerate] Loading slump data …")
    dataset = load_concrete_strength(Y_columns=SLUMP_Y_COLUMNS)
    slump = dataset.slump_data
    if slump is None:
        raise RuntimeError("slump_data is None; check the 'Slump (in)' column.")
    X, Y, Yvar, _bounds = slump
    print(f"[regenerate]   X={tuple(X.shape)} Y={tuple(Y.shape)}")

    # Compare the full column LIST, not just its length: docs/slump.mjs
    # hardcodes I_CEMENT=0 / I_FLYASH=1 / I_SLAG=2 / I_HRWR=4 and this file
    # hardcodes source_dim_raw=7, so a reordering of DEFAULT_X_COLUMNS would
    # silently corrupt the derived feature and the mortar gate while still
    # producing a parity-passing artifact (both sides regenerate the same
    # wrong thing). X_columns[:-1] drops "Time", which slump_data strips.
    if list(dataset.X_columns[:-1]) != RAW_FEATURE_NAMES:
        raise RuntimeError(
            "RAW_FEATURE_NAMES is out of sync with DEFAULT_X_COLUMNS: "
            f"expected {RAW_FEATURE_NAMES}, got {list(dataset.X_columns[:-1])}. "
            "docs/slump.mjs hardcodes column indices and slump.json hardcodes "
            "source_dim_raw=7; both must be revisited with this list."
        )

    observed = sorted({int(v) for v in X[:, 7].tolist()})
    if observed != SUPPORTED_SOURCE_CLASSES:
        raise RuntimeError(
            f"Slump source classes changed: expected {SUPPORTED_SOURCE_CLASSES}, "
            f"found {observed}. The explorer's mortar gate in docs/ui.mjs and the "
            "supported_source_classes field must be revisited together."
        )

    print("[regenerate] Fitting slump GP …")
    model = fit_slump_gp(X, Y, Yvar)
    model.eval()

    # --- Refuse to export an architecture the JS port cannot reproduce. ---
    # docs/slump.mjs implements exactly: ConstantMean + ARD RBF (outputscale 1)
    # + Standardize + Normalize + AppendDerivedFeatures. If BoTorch's
    # SingleTaskGP defaults move, this fails loudly here rather than shipping
    # a silently-wrong artifact.
    if not isinstance(model.covar_module, RBFKernel):
        raise RuntimeError(
            f"docs/slump.mjs implements ARD RBF; model uses "
            f"{type(model.covar_module).__name__}. Update both together."
        )
    if hasattr(model.covar_module, "outputscale"):
        raise RuntimeError(
            "Kernel gained an outputscale (ScaleKernel). Export it and teach "
            "docs/slump.mjs to read params.outputscale from the artifact."
        )
    if not isinstance(model.mean_module, ConstantMean):
        raise RuntimeError(
            f"docs/slump.mjs implements ConstantMean; model uses "
            f"{type(model.mean_module).__name__}."
        )
    if not isinstance(model.outcome_transform, Standardize):
        raise RuntimeError(
            f"docs/slump.mjs implements Standardize; model uses "
            f"{type(model.outcome_transform).__name__}."
        )

    with torch.no_grad():
        lengthscales = model.covar_module.lengthscale.detach().flatten().tolist()
        noise = float(model.likelihood.noise.detach().flatten()[0])
        mean_constant = float(model.mean_module.constant.detach().flatten()[0])
        y_mean = float(model.outcome_transform.means.detach().flatten()[0])
        y_std = float(model.outcome_transform.stdvs.detach().flatten()[0])
        norm = model.input_transform["normalize"]
        lower = norm.bounds[0].detach().tolist()
        upper = norm.bounds[1].detach().tolist()
        train_X_aug = model.train_inputs[0].detach()  # [n, 10], post-transform
        train_Y_std = model.train_targets.detach()  # [n], standardized

    d_aug = train_X_aug.shape[-1]
    print(f"[regenerate]   d_in={X.shape[-1]} d_aug={d_aug} n={train_X_aug.shape[0]}")
    print(f"[regenerate]   noise={noise:.6f} mean_constant={mean_constant:.6f}")
    print(f"[regenerate]   y_mean={y_mean:.4f} in  y_std={y_std:.4f} in")

    out = {
        "schema_version": 1,
        "model_name": "slump_gp_v1",
        "comment": (
            "Slump GP for the web explorer. BoTorch SingleTaskGP defaults: "
            "ConstantMean + ARD RBF (no ScaleKernel, so outputscale is 1) + "
            "Standardize(1) outcome transform. Inputs are the 9 composition "
            "dims (no Time) with the HRWR/binder ratio appended by "
            "boxcrete.features.AppendDerivedFeatures, then min-max normalized. "
            "Trained only on Material Source 1 and 2 — mortar (class 0) has no "
            "slump measurements. Generated by "
            "experiments/regenerate_slump_json.py; do not edit by hand."
        ),
        "d_in": int(X.shape[-1]),
        "d_aug": int(d_aug),
        "n_train": int(train_X_aug.shape[0]),
        "raw_feature_names": RAW_FEATURE_NAMES,
        "engineered_feature_names": ["hrwr_binder_clamped"],
        "source_dim_raw": 7,
        "supported_source_classes": SUPPORTED_SOURCE_CLASSES,
        "normalize_lower": lower,
        "normalize_upper": upper,
        "kernel_kind": "rbf_ard",
        "lengthscales": lengthscales,
        "outputscale": 1.0,
        "mean_kind": "constant",
        "mean_constant": mean_constant,
        "noise": noise,
        "variance_includes_aleatoric": True,
        "y_scaling": "standardize",
        "y_mean": y_mean,
        "y_std": y_std,
        "y_units": "in",
        "X_train": train_X_aug.tolist(),
        "Y_train": train_Y_std.tolist(),
    }
    OUT.write_text(json.dumps(out) + "\n")
    print(f"[regenerate] Wrote {OUT.relative_to(REPO)}")

    _write_test_vectors(model, X)


def _write_test_vectors(model, X: torch.Tensor) -> None:
    """Golden posteriors from the SAME fit, for test/test_js_slump.mjs."""
    torch.manual_seed(SEED + 1)
    n_random = 24

    lo, hi = X.min(dim=0).values, X.max(dim=0).values
    rand = lo + (hi - lo) * torch.rand(n_random, X.shape[-1], dtype=X.dtype)
    # Material Source is categorical: snap to an observed class.
    rand[:, 7] = torch.tensor(
        [SUPPORTED_SOURCE_CLASSES[i % 2] for i in range(n_random)], dtype=X.dtype
    )
    # Include every training point too — these must reproduce near-exactly.
    probes = torch.cat([X, rand], dim=0)

    with torch.no_grad():
        # observation_noise=True matches variance_includes_aleatoric in the
        # artifact and the +noise term in docs/slump.mjs.
        post = model.posterior(probes, observation_noise=True)
        means = post.mean.flatten().tolist()
        variances = post.variance.flatten().tolist()

    vectors = [
        {
            "input": probes[i].tolist(),
            "expected_mean": means[i],
            "expected_variance": variances[i],
        }
        for i in range(probes.shape[0])
    ]
    OUT_VECTORS.write_text(
        json.dumps(
            {
                "comment": (
                    "Golden slump posteriors (inches, observation_noise=True) from "
                    "the same fit that produced slump.json. Regenerate both together "
                    "via experiments/regenerate_slump_json.py."
                ),
                "model_name": "slump_gp_v1",
                "test_vectors": vectors,
            }
        )
        + "\n"
    )
    print(
        f"[regenerate] Wrote {OUT_VECTORS.relative_to(REPO)} "
        f"({len(vectors)} vectors)"
    )


if __name__ == "__main__":
    main()
```

### 3a. Write the test

```js
/**
 * Port-equivalence test: docs/slump.mjs (fed by docs/model/slump.json) must
 * reproduce the Python posteriors baked into docs/model/slump_test_vectors.json
 * by experiments/regenerate_slump_json.py.
 *
 * Both files come from a single fit — regenerate them together.
 *
 * Run: node test/test_js_slump.mjs
 */

import { readFileSync } from "fs";
import { dirname, join } from "path";
import { fileURLToPath } from "url";

const __dirname = dirname(fileURLToPath(import.meta.url));
const REPO_ROOT = join(__dirname, "..");

const { initSlumpModel, predictSlump, augmentSlumpInput } = await import(
  join(REPO_ROOT, "docs", "slump.mjs")
);

const params = JSON.parse(
  readFileSync(join(REPO_ROOT, "docs", "model", "slump.json"), "utf-8")
);
const golden = JSON.parse(
  readFileSync(join(REPO_ROOT, "docs", "model", "slump_test_vectors.json"), "utf-8")
);

initSlumpModel(params);

const RTOL = 1e-6;
const ATOL = 1e-8;

let passed = 0;
const failures = [];

function assertClose(actual, expected, name) {
  const absErr = Math.abs(actual - expected);
  const relErr = Math.abs(expected) > ATOL ? absErr / Math.abs(expected) : absErr;
  if (relErr > RTOL && absErr > ATOL) {
    failures.push(
      `${name}: expected ${expected}, got ${actual} ` +
        `(relErr=${relErr.toExponential(2)}, absErr=${absErr.toExponential(2)})`
    );
  } else {
    passed++;
  }
}
```

## Step 4: Implement `docs/slump.mjs`

**File** (new): `/Users/sebastianament/Code/SustainableConcrete-slump/docs/slump.mjs`

### 4a. Write the module

```js
// Client-side slump (workability) GP posterior for the explorer readout.
//
// Deliberately separate from `gp.mjs`. That module's `transformInput` and
// `kernel` are hardwired to the strength architecture — they log-scale a time
// dimension and multiply in a time gate that a time-independent slump model
// does not have. Threading schema flags through the app's hottest path to save
// ~50 lines here is a bad trade. The linear algebra IS shared: `cholesky` and
// `solveTriangularLower` are imported rather than reimplemented.
//
// Fed by `docs/model/slump.json` (see `experiments/regenerate_slump_json.py`).
// Architecture: ConstantMean + ARD RBF (outputscale 1) + Standardize(1), over
// the 9 composition dims with HRWR/binder appended and min-max normalization.

import { cholesky, solveTriangularLower } from "./gp.mjs";

const I_CEMENT = 0;
const I_FLYASH = 1;
const I_SLAG = 2;
const I_HRWR = 4;

// Append HRWR/binder, matching `boxcrete.features.AppendDerivedFeatures`:
// the binder is CLAMPED at 1.0, not offset by 1.0. `FEATURE_FNS.hrwr_binder`
// in `feature_registry.mjs` is the strength model's `binder + 1.0` variant and
// must not be substituted here — the two disagree by ~0.3% on real mixes.
export function augmentSlumpInput(composition) {
  const binder = Math.max(
    composition[I_CEMENT] + composition[I_FLYASH] + composition[I_SLAG],
    1.0,
  );
  return [...composition, composition[I_HRWR] / binder];
}

// Min-max to the unit cube. Intentionally unclamped, mirroring BoTorch's
// `Normalize`: a composition outside the training hull maps outside [0, 1],
// the kernel decays, and the posterior widens toward the prior. That is the
// honest answer, and the readout's ±2σ carries it to the user.
function normalize(xAug, params) {
  const lower = params.normalize_lower;
  const upper = params.normalize_upper;
  const out = new Array(xAug.length);
  for (let d = 0; d < xAug.length; d++) {
    const span = upper[d] - lower[d];
    out[d] = span === 0 ? 0 : (xAug[d] - lower[d]) / span;
  }
  return out;
}

function rbfARD(a, b, lengthscales, outputscale) {
  let acc = 0;
  for (let d = 0; d < a.length; d++) {
    const z = (a[d] - b[d]) / lengthscales[d];
    acc += z * z;
  }
  return outputscale * Math.exp(-0.5 * acc);
}

/**
 * One-time setup: rebuild K, factor it, solve for alpha. Mutates `params`
 * with `_L` and `_alpha`. Idempotent.
 *
 * Like the strength path, the artifact ships kernel ingredients rather than a
 * precomputed factorization, so JS and Python reach the same K from the same
 * kernel evaluations instead of inheriting Python's Cholesky. n = 61 here, so
 * this is microseconds — no worker needed, unlike `initStrengthModel`.
 */
export function initSlumpModel(params) {
  if (params._alpha) return params;

  if (params.schema_version !== 1) {
    throw new Error(
      `slump.mjs supports schema_version 1, got ${params.schema_version}`,
    );
  }
  if (params.kernel_kind !== "rbf_ard") {
    throw new Error(`slump.mjs supports kernel_kind "rbf_ard", got "${params.kernel_kind}"`);
  }
  if (params.mean_kind !== "constant") {
    throw new Error(`slump.mjs supports mean_kind "constant", got "${params.mean_kind}"`);
  }
  if (params.y_scaling !== "standardize") {
    throw new Error(`slump.mjs supports y_scaling "standardize", got "${params.y_scaling}"`);
  }

  const X = params.X_train;
  const n = X.length;
  const { lengthscales, outputscale, noise, mean_constant: m } = params;

  const K = [];
  for (let i = 0; i < n; i++) {
    K.push(new Array(n));
  }
  for (let i = 0; i < n; i++) {
    K[i][i] = outputscale + noise;
    for (let j = 0; j < i; j++) {
      const k = rbfARD(X[i], X[j], lengthscales, outputscale);
      K[i][j] = k;
      K[j][i] = k;
    }
  }

  const L = cholesky(K);
  // alpha = K^-1 (y - m), via forward then back substitution.
  const centered = params.Y_train.map((y) => y - m);
  const z = solveTriangularLower(L, centered);
  const alpha = new Array(n);
  for (let i = n - 1; i >= 0; i--) {
    let acc = z[i];
    for (let j = i + 1; j < n; j++) acc -= L[j][i] * alpha[j];
    alpha[i] = acc / L[i][i];
  }

  params._L = L;
  params._alpha = alpha;
  return params;
}

/**
 * Posterior slump for one composition, in INCHES (the units the data is
 * stored in — see `boxcrete/units.py`). Callers convert for display.
 *
 * @param {number[]} composition - 9 raw dims, no Time. Must match
 *   `params.raw_feature_names` order.
 * @param {object} params - Parsed `slump.json`, after `initSlumpModel`.
 * @returns {{mean: number, variance: number}} inches and inches².
 */
export function predictSlump(composition, params) {
  if (!params._alpha) {
    throw new Error("predictSlump: call initSlumpModel(params) first");
  }
  if (composition.length !== params.d_in) {
    throw new Error(
      `predictSlump: expected ${params.d_in} raw dims, got ${composition.length}`,
    );
  }

  const { lengthscales, outputscale, _L: L, _alpha: alpha } = params;
  const X = params.X_train;
  const n = X.length;
  const xn = normalize(augmentSlumpInput(composition), params);

  const kStar = new Array(n);
  let meanStd = params.mean_constant;
  for (let i = 0; i < n; i++) {
    const k = rbfARD(X[i], xn, lengthscales, outputscale);
    kStar[i] = k;
    meanStd += k * alpha[i];
  }

  const v = solveTriangularLower(L, kStar);
  let varStd = outputscale;
  for (let i = 0; i < n; i++) varStd -= v[i] * v[i];
  if (params.variance_includes_aleatoric) varStd += params.noise;
  // Numerically, subtracting v·v from outputscale can dip below zero at a
  // training point. Clamp rather than emit a NaN std downstream.
  if (varStd < 0) varStd = 0;

  const s = params.y_std;
  return {
    mean: meanStd * s + params.y_mean,
    variance: varStd * s * s,
  };
}

/** Whether this material source class has slump training data. */
export function slumpSupportsSource(sourceClass, params) {
  return params.supported_source_classes.includes(Math.round(sourceClass));
}
```

### 14b. Parameterize the drift helpers, then add slump checkers

`assert_variance_close` (`check_artifacts_drift.py:143-160`) takes **no tolerance arguments** —
it hardcodes `VARIANCE_PSI2_FLOOR = 2000.0` (line 79). Slump variances are in inches²
(≈ 2–11), so `delta = max(2000, 0.05·v)` is always `2000` and *every* drift passes. The check
would be vacuous by three orders of magnitude. Parameterize first, keeping the strength
callers on defaults:

```python

        self,
        committed: float,
        fresh: float,
        *,
        floor: float = VARIANCE_PSI2_FLOOR,
        rtol: float = VARIANCE_RTOL,
        unit: str = "psi^2",
        label: str,
    ) -> None:
```

…using `floor` / `rtol` / `unit` in the body and the failure message. Do the same for
`assert_prediction_close` (line 123): rename `psi_floor` to `floor`, add `unit: str = "psi"`,
and replace the hardcoded `" psi"` in its message at line 139. Update the three existing call
sites (lines 267, 288, 321).

`check_strength_json` (191) and `check_test_vectors_json` (252), and register them in the

```python

```
